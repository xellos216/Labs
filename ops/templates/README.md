# Operations Templates

Reusable document templates live here. The current template is:

- [`session_archive_ko.md`](session_archive_ko.md) for one completed session
  archive written in Korean

The authoritative format rules are in [Session Archive
Format](../docs/SESSION_ARCHIVE_FORMAT.md). A template is not progress evidence
and must not be copied into a roadmap before the session is complete and the
learner approves archive generation.
