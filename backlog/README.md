# Backlog Roadmaps

`backlog/` contains complete curriculum specifications that are not currently
active:

- [Web Security](web_security/README.md)
- [Bug Bounty Operations](bug_bounty/README.md)
- [Wired Network Security](wired_network/README.md)
- [Wireless Security](wireless_security/README.md)
- [Linux Internals](linux_internals/README.md)

Backlog status does not mean that a specification is unfinished. Activate a
roadmap only after its prerequisites and environment requirements are met,
then move the complete roadmap directory to `active/` and update the [Roadmap
Index](../ops/docs/ROADMAP_INDEX.md).
